# Hamza Boufass — Portfolio

Portfolio personnel bilingue de Hamza Boufass, UX/UI Designer et Digital Designer basé à Casablanca.

## Démarrer le projet

```powershell
npm install
npm run dev
```

Ouvrir ensuite `http://localhost:3000`.

## Contenu

- Accueil disponible en français et en anglais
- Profil, expertise et parcours basés sur le CV
- Étude de cas : Morocco Franchise Exhibition — BILL APP
- Les prochains projets sont ajoutés à la liste de cartes empilées de l’accueil
